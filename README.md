# Personal Developer Roadmap & Dashboard

> Inspired by [roadmap.sh](https://roadmap.sh)

A modern, responsive personal developer dashboard and interactive skills roadmap featuring real-time local time tracking and customizable developer profile.

## ✨ Features

- **Roadmap.sh UI/UX Aesthetic**: Dark theme canvas (`#080c14`), dotted background grid, and high-contrast roadmap nodes.
- **Developer Identity Card**: Displays developer name, title, status pill, bio, and quick links. Includes inline edit functionality saved to `localStorage`.
- **Real-Time Live Clock & Metrics**:
  - Live ticking digital clock with 12h/24h toggle.
  - Formatted local date and timezone indicator.
  - Dynamic **Day Progress Bar** & **Year Progress Bar**.
- **Interactive Skills Roadmap Flowchart**:
  - 4 stages of developer milestones (Foundations, Embedded Core, Advanced Firmware & IoT, Next Frontier).
  - Interactive status tagging (`Done`, `In Progress`, `Planned`) with pulse animations.
  - Slide-over topic drawer with key learning points and resources.
- **Zero-Build Architecture**: Runs directly in any browser via CDN-delivered Tailwind CSS and Lucide icons.

## 🚀 Quick Start

Simply open `index.html` in your browser:

```bash
# Or serve with Python
python -m http.server 8000
```
